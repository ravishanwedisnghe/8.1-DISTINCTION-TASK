# Sydney House Price Predictor

This project uses machine learning to estimate house sale prices in Penrith, Leichhardt and Turramurra.

## Project Files

- `8.1_DISTINCTION_TASK.ipynb` – project code and results
- `app.py` – Streamlit application
- `house_price_model.pkl` – trained Random Forest model
- `requirements.txt` – required Python libraries
- `sydney_three_suburbs_houses (1).csv` – property dataset

## How to Run

1. Download the project files.
2. Install the required libraries:

pip install -r requirements.txt

3. Start the application:

streamlit run app.py

## Important Note

The prediction is based on 110 historical house sales from 2016 to 2021. It is only an estimate and should not replace a professional property valuation.
